Measured on Awwwards portfolio winners (2026-09-15):
- Grounds: nobody uses pure #000/#fff as the only pair. Dark #0a0a0a/#121212/#1a1c1c;
  light warm off-whites #f7f7f7/#efedea/#ede7de/#fefff8.
- Near-monochrome + ≤1 accent used tiny (Mangham violet #5e2bff dots only; Jam Area red
  cursor dot #e0110f). Colour comes from project thumbnails.
- Type: grotesk + mono (mono for all metadata 10–12px caps) OR grotesk + one serif-italic
  word. Display tracking always negative −2% to −5% (Pacôme −4px@80px, Form&Fun
  −2.88px@101px, Lama Lama −1.44px@72px). Huge scale jumps (Jam Area 15/21/159/339px).
- Motion: Lenis on 9/10; GSAP on 5/10; SplitType 2; Barba 1. Easings all strong ease-out:
  .16,1,.3,1 (Podium) · .19,1,.22,1 expo (Jam Area) · .23,1,.32,1 (Form&Fun = Emil) ·
  .39,.575,.565,1 (Mangham) · .11,.82,.39,.92 (Olha); page moves .9,0,.1,1 (Adcker) or
  .5,0,0,1 (Studio Null, 0.8 s). Hovers 0.2–0.3 s, reveals 0.5–1.25 s. Only 2/10 had
  reduced-motion CSS. Custom cursor on 6/10.
- Loaders are typographic: % counter + dot (Podium), % alone (Lama Lama),
  "*( [cycling image] ) 31%" that previews the hero (Adcker), 3D mascot + one line (Pacôme),
  "ENTER / Enter site without audio" gate (Studio Null).
- Layout moves: project rows with mono chips + "( + )" (Lama Lama); mono info grid with local
  time "LON [18:15]", "Available September 2026", bracket buttons ⌜SCHEDULE CALL⌟ (Mangham);
  sans + serif name edge to edge (Yakushev); photos inside headline brackets (Adcker,
  Gradogna "THROUGH THIS [photo] LENS"); scattered letters reassembling on scroll (Olha);
  floating copper project card on split photos + film grain (MERSI); LIST VIEW toggle (Podium).
- Free font stand-ins: Neue Montreal → Geist (85%)/Inter (88%)/DM Sans; Suisse → Inter (90%);
  free faces winners use: Sofia Sans Condensed, Spline Sans Mono, Switzer (Fontshare), Kumbh Sans.
- UI/UX Pro Max generic suggestion (Brutalism, #000, Archivo + Space Grotesk, back.out bounce)
  was REJECTED in favour of measured data.
